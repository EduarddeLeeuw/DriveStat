# DriveStat

This web application can be used to track statistics of a vehicle, such as gas/energy consumption and trip data. It includes well-organized graphs and a monthly energy cost overview.

## Installation

### Prerequisites

* Git
* Docker

### Setup

Download and the Docker project and navigate to the correct directory:
```bash
git clone https://github.com/EduarddeLeeuw/DriveStat.git
cd DriveStat
```

## Getting Started

First, build and start the containers:
```bash
docker compose up -d --build
```
 After that, the webserver should be running at http://localhost.
